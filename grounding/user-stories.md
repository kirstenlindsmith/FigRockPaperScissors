# User Stories

## Start a battle without deciding anything

The user opens the app and, in one tap, is looking at a battlefield with the armies drawn up and waiting. A second tap sends them in and starts the clock.

## Watch a battle resolve

The battle needs no input. Throughout, the user can see how long it has run and how large each army is. Every battle ends with one army standing, and the winner is celebrated.

## Command time

The user pauses a battle, resumes it, restarts it, abandons it, and accelerates it when it drags.

## Make the armies their own

The user chooses which emoji fight, what each army is called, and how many of each. The three roles keep their names so a watcher can learn which beats which; when the app names one particular army, it uses the name the user gave it. Before a battle begins, the user can take the field in hand — clearing it, erasing soldiers, painting new ones with a fingertip — drawing with the three emoji they chose, up to the numbers they set. The field they compose is the field they fight from. The app opens ready to fight with the setup last chosen.

## Field armies of any size

The user can field far more soldiers than fit comfortably on a phone, and still see every one of them. When a soldier is too small to make out, the user pinches to zoom and drags to move around the field — before a battle and while one runs. Nothing a battle needs sits behind those gestures. The limit is whatever a real phone can carry.

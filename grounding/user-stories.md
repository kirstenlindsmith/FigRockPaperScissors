# User Stories

## Start a battle without deciding anything

The user opens the app and, in one tap, is looking at a battlefield with the armies drawn up and waiting. A second tap sends them in and starts the clock.

## Watch a battle resolve

The battle needs no input. Throughout, the user can see how long it has run and how large each army is. Every battle ends with one army standing, and the winner is celebrated.

## Command time

The user pauses a battle, resumes it, restarts it, abandons it, and accelerates it when it drags.

## Make the armies their own

The user chooses which emoji fight, how many of each there are, and where every soldier stands. The app opens ready to fight with the setup last chosen.

## Field armies of any size

The user can field far more soldiers than fit comfortably on a phone, and still see every one of them. The limit is whatever a real phone can carry.
